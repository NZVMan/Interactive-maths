Factorising quadratics

By the end of this lesson you can:
  • factorise x² + bx + c by finding two numbers that multiply to c and add to b
  • factorise ax² + bx + c when a is more than 1
  • check a factorisation by expanding it

1. Quadratics with x² on its own

Factorising x² + bx + c is expanding (x + p)(x + q) backwards.

Find two numbers p and q that multiply to c and add to b. Then x² + bx + c = (x + p)(x + q).

Check by expanding. If c is positive, p and q have the same sign as b. If c is negative, they have different signs.

Predict first: To factorise x² + 5x + 6, which pair of numbers multiplies to 6 and adds to 5: 1 and 6, or 2 and 3?
Check my prediction

2 and 3. 2 × 3 = 6 and 2 + 3 = 5. (1 and 6 multiply to 6 but add to 7.) So x² + 5x + 6 = (x + 2)(x + 3).

Type the numbers in ax² + bx + c. Try a = 1 first.

2. When a is not 1

For ax² + bx + c, find two numbers that multiply to a × c and add to b. Use them to split the middle term, then factorise in pairs.

Example: 2x² + 7x + 3. a × c = 6, and 1 + 6 = 7. Write 2x² + x + 6x + 3 = x(2x + 1) + 3(2x + 1) = (x + 3)(2x + 1).

Try a = 2 in the applet above, for example a = 2, b = 7, c = 3.

3. Taking out a common factor first

Always look for a common factor first. 2x² + 10x + 12 = 2(x² + 5x + 6) = 2(x + 2)(x + 3).
