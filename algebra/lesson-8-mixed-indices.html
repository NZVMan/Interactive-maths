Mixed index practice

By the end of this lesson you can:
  • combine the index laws to simplify expressions with several letters
  • simplify expressions and give answers with positive indices
  • spot which index statements are true and which are false

1. All the laws together

Multiply: add indices. Divide: subtract indices. Power of a power: multiply indices. a⁰ = 1 and a⁻ⁿ = 1/aⁿ.

Work on the numbers and on each letter separately. Always say which law you are using.

Simplify (2x³)² ÷ x.

(2x³)² = 4x⁶

4x⁶ ÷ x = 4x⁵

2. Answers with positive indices

Sometimes the subtraction gives a negative index. Write it as a fraction: 6x² ÷ 3x⁵ = 2x⁻³ = 2/x³.

3. Test a rule with numbers

If you aren't sure a rule is true, try numbers. If it fails for even one value, the rule is false. Type two expressions with x and y and compare them.

Predict first: Is (x²)³ equal to x⁵?
Check my prediction

No. (x²)³ = x⁶ (multiply the indices). Try x = 2: (2²)³ = 4³ = 64, but 2⁵ = 32.
